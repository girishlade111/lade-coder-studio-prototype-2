# **App Name**: Lade Coder

## Core Features:

- Landing Page: Clean, minimal landing page with a central prompt bar.
- Prompt Optimization: Optimize Prompt: Use AI as a tool to rewrite the user's prompt into a detailed, high-quality version.
- Main Workspace Layout: Main Workspace: Left sidebar for prompt & chat panel, right main section with code and live preview tabs.
- Version History: Version History: List of all generated code versions with timestamps and a restore button for each version.
- Live Preview and Code Modification: Live Preview: AI modifies the existing codebase with diff-based updates based on follow-up prompts and allows restoring previous versions
- Live Preview: Live Preview: Renders generated code inside an iframe with responsive device toggles and "Open in New Tab" functionality.
- Template Suggestions: Template Suggestions: After a prompt, AI can suggest three pre-made template variants as a starting point.

## Style Guidelines:

- Primary color: Light pastel purple (#D0BFFF), reflecting creativity and digital innovation.
- Background color: Very light grey (#F5F5F5) to provide a clean, uncluttered backdrop.
- Accent color: Muted blue (#A0C4FF) for interactive elements and highlights, providing subtle contrast.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral, and readable experience.
- Code font: 'Source Code Pro' (monospace) for displaying code snippets in the Monaco Editor.
- Minimalist line icons for buttons and controls to maintain a clean, uncluttered design.
- Responsive layout using React and Tailwind, adapting seamlessly to different screen sizes and devices.
- Smooth, subtle animations using Framer Motion for transitions and interactions, such as the prompt bar minimizing into the sidebar.
